Jak spustit na GitHub Pages

  1. Vytvořte nové repozitář na GitHubu:
    Přejděte na github.com/new, pojmenujte ho např. jidelna-ms a klikněte na Create repository.
  2. Vložte soubor index.html:
    Uložte tento kód do souboru s názvem index.html a nahrajte jej do svého repozitáře (tlačítko Add file > Upload files nebo přímo vytvořte nový soubor).
  3. Aktivujte GitHub Pages:
    V repozitáři jděte do Settings → Pages.
    V části Build and deployment / Branch vyberte větev main (nebo master) a složku / (root). Klikněte na Save.
  4. Hotovo!
    Během 1-2 minut bude váš jídelníček dostupný na adrese:
    https://vas-nick.github.io/jidelna-ms/

Ruční úprava / Vložení dat

Pokud selže živý přenos ze Strava.cz kvůli blokování CORS, můžete si zde editovat nebo vložit data v JSON formátu.
